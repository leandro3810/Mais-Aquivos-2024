## Arquitetura do Agente (MVP)

O agente executa um fluxo sequencial em três camadas:

1. **`AgentMemory`** — histórico circular (FIFO) com até 20 registros da execução atual
2. **`ToolLayer`** — ferramentas concretas com bloqueio de comandos destrutivos e caminhos sensíveis
3. **`AgentOrchestrator`** — coordena o fluxo e produz sumário em texto ou JSON

### Fluxo padrão de execução

```
git status --porcelain
    → rodar testes (unittest discover)
        → validar arquivos JSON de configuração
            → gerar sumário final
```
